# Le Baobab

Site de restaurant gastronomique (fictif, Cotonou) : accueil immersif, carte filtrable, galerie avec lightbox, réservation en 4 étapes avec calendrier personnalisé, espace « Mes réservations », contact et badge « ouvert maintenant ».

**Stack** : React 18, Vite 5, Tailwind CSS 3, Framer Motion, React Router.

```bash
npm install
npm run dev
npm run build
```

Fermé le lundi. Les créneaux « complets » sont simulés de façon stable. Les réservations sont enregistrées dans le navigateur (localStorage).
